# KINETIC LAB

> Three.js 기반 정적 3D 모션·파티클 VFX 실험실
>
> **이 프로젝트는 비군사적 시각화 데모입니다.** 이름이 붙은 여섯 스타일은 임의의 아트 디렉션으로 만든 추상적 3D 모형입니다. 실제 군사 장비의 설계, 운용, 유도, 사거리, 추진력, 폭발력이나 탄도를 나타내지 않습니다.

## 데모 기능

- 6개 스타일 레이블: 현무, 스커드, 이스칸데르, 화성포, 불화살, 바다수리
- **라이트·다크 모드**: OS 테마 자동 인식, 상단 토글, 브라우저 로컬 저장을 통한 설정 유지
- **추상적 시각효과 모드 3종**: 장사정포 / 자주포 / 해안포 — 실제 제원을 참고하지 않은 외형·빛·색상 연출
- **가상 구조물 3개**: 건물 A/B/C를 버튼이나 3D 화면 클릭으로 선택
- **구조물 분해 효과**: 발광 구체의 시네마틱 이동, 건물 조각의 중력·항력·충돌·감쇠 반발, 자동 복원 및 수동 복원
- **능선 실루엣과 장식용 구조물**: 사용자가 제공한 개념도에서 지형의 분위기만 참고하며 실제 전술을 재현하지 않음
- Three.js WebGL 3D 장면, 모형 스테이션, OrbitControls 카메라
- 단발 모션 / 연속 재생 / 선택 스타일 순환 / 재생 간격 및 속도 조절
- 비행 경로는 실제 데이터가 아닌 **정규화된 시네마틱 곡선**으로 처리
- 공중 파티클 연출: 발광 스파크, 연기, 일시적 조명, 원형 충격파
- 장식용 파편에 **고정 시간 간격의 단순 물리 업데이트**, 중력·항력·바닥 충돌·감쇠 반발
- 실시간 FPS, 활성 3D 오브젝트와 파티클 개수, 이벤트 기록
- 고화질 / 균형 / 절전 프리셋, 저사양 자동 보호, 모바일 대응
- 자체 서버·DB·빌드·GitHub Actions·런타임 추적 도구 없음

## 기술 구성

## 로컬 실행

정적 서버에서 루트 파일을 서빙하세요. 모듈 import 때문에 파일을 직접 더블클릭하여 file:// 형태로 여는 것은 지원하지 않습니다.

Python 3을 사용하는 경우:

    python -m http.server 8080

브라우저에서 http://localhost:8080 으로 접속합니다.

물리 업데이트 단위 테스트(Node.js 20 이상):

    npm test

## 무료 정적 배포

**Cloudflare Pages**: GitHub 저장소 hslcrb/missile-system 을 연결하고, Production branch는 main, 프레임워크 프리셋은 None, 빌드 명령은 비움, 출력 디렉터리는 프로젝트 루트(.)로 설정합니다. GitHub Actions 없이 GitHub 커밋과 연동할 수 있습니다.

**GitHub Pages**: Settings → Pages → Build and deployment → Deploy from a branch → main / root 를 선택합니다. 실제 사이트 주소는 해당 서비스에서 배포가 성공한 후 확인해야 합니다.

이 저장소 작업은 소스코드 업로드까지이며 별도의 호스팅 서비스 활성화가 자동으로 보장되지는 않습니다.

## 조작법

- 왼쪽: 디자인 스타일 선택 후 단일 모션 또는 연속 재생
- 라이트/다크: 상단 LIGHT/DARK 토글 (선택 사항은 해당 브라우저에만 저장)
- 체험 모드: 비행 모션 / 장사정포 / 자주포 / 해안포. 실제 발사체의 사격술과 무관한 추상적 3D 연출
- 가상 구조물: 장사정포·자주포·해안포 모드에서 A/B/C 버튼 또는 3D 화면 건물 클릭으로 선택
- 효과 재생 후 가상 건물이 여러 조각으로 분해되며 시간이 지나면 자동 복원. '모든 구조물 복원'도 제공
- 모델 순환을 켜면 여섯 스타일의 애니메이션을 번갈아 재생
- 장면: 드래그 회전, 휠 줌, 우클릭 이동
- ISOMETRIC / WIDE / GROUND / STRUCTURES 카메라 프리셋
- 단축키: L 단일 모션, P 일시정지, Esc 연속 재생 중지

## 그래픽 성능 및 구현 원칙

- 동일한 파편 형태는 InstancedMesh로 묶어 그리기 호출을 절약
- 가상 건물 창문 역시 InstancedMesh 사용, 가상 건물 조각 최대 360개 풀 재사용
- 효과 대상은 오직 장면 내 고정된 가상 구조물 3개이며 외부 좌표·실제 건물 데이터·지도·탄도 입력 기능은 없음
- 발광 스파크와 연기는 BufferGeometry + ShaderMaterial 방식의 파티클 풀
- 생성 개수에 상한을 두어 오브젝트와 파티클이 무한히 쌓이지 않도록 구성
- 시뮬레이션 효과에 고정 간격(1/60초) 업데이트와 프레임당 최대 업데이트 횟수 제한
- 캔버스 해상도는 디바이스 DPR과 품질 프리셋 중 낮은 값으로 제한
- 창 크기 변경 반영, 탭 비활성화 후 프레임 간격 제한, 저성능 기기용 품질 자동 하향

## 안전성과 한계

화면의 폭발과 가상 건물 붕괴는 **연출된 파티클·기하학 그래픽**입니다. 실물 폭발·고충실도 유체해석·충격파 공학 시뮬레이션이나 물리적인 파괴 현상이 아닙니다. 실물 모델과 일치하는 3D 형상, 탄도 데이터, 유도 로직, 조준/표적 선택, 군사 장치 연결, 제어 신호가 없습니다.

브라우저와 그래픽 장치에 따라 프레임 속도는 달라집니다. 소스만으로 실제 배포 성능을 보증하지 않습니다.
